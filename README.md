## 🛠️ How to Install (Load Unpacked)

1. **Clone or Download this repository:**
   ```bash
   git clone https://github.com/harmless-bot/harmless-course-completer.git
   ```
   Or navigate to your local folder:
   ```bash
   /Users/divyanshurai/projects/harmless-course-completer
   ```

2. **Load into Google Chrome / Brave / Edge / Arc / Opera:**
   * Open `chrome://extensions/` in your browser.
   * Toggle **Developer mode** in the top-right corner.
   * Click **Load unpacked** in the top-left corner.
   * Select the folder: `/Users/divyanshurai/projects/harmless-course-completer`
   * Pin **🚽 Skibidi AutoPilot** to your browser toolbar!

3. **Mog Your First Course:**
   * Open any course on [Coursera](https://www.coursera.org/) or [LinkedIn Learning](https://www.linkedin.com/learning/).
   * Watch the floating Skibidi HUD appear in the bottom-right corner.
